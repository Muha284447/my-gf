# Сайт для Али — День Подруги

## Как посмотреть
Открой `index.html` в любом браузере (просто дважды кликни по файлу).

## Что нужно доделать перед отправкой

1. **Фото** — добавь `photo1.jpg` … `photo7.jpg` в папку `assets/photos/` (подробности в README.txt внутри этой папки). Фото расставлены по всему сайту: у имени в начале, лентой из двух штук после хедера, две внутри письма, одно в углу блока с сердечками, и одно в самом конце.
2. **Музыка** — добавь `our-song.mp3` в `assets/music/`. Кнопка-сердечко в правом верхнем углу включит её.
3. **Письмо** — открой `index.html`, найди блок `<section class="letter">` и заполни два места в квадратных скобках:
   - `[момент или шутку, только для неё]`
   - `[то самое, что ты в ней любишь]`
   - подпишись вместо `[Твоё имя]`
4. **6 "причин, почему я тебя люблю"** и подписи под фото — обычный текст в `index.html`, редактируй как захочешь.

## Как отправить ей сайт
Когда всё будет готово, можно:
- заархивировать всю папку `Gf day` и отправить ей, или
- бесплатно захостить (GitHub Pages, Netlify, Vercel) и просто скинуть ссылку.

Скажи, если нужна помощь с архивацией или публикацией онлайн.
